# E-Inventory releases

Installers and automatic updates for E-Inventory, the inventory app for the SJPI Electrical Division.

Download the latest `E-Inventory-Setup-x.y.z.exe` from [Releases](https://github.com/kkhinds/e-inventory-releases/releases/latest) and run it. Windows may say "Windows protected your PC": choose More info, then Run anyway. Once installed, E-Inventory updates itself from here.
